# Proposal

## Why

Currently, the supply chain anomaly detection system analyzes movements and generates anomalies via the API, but there is no graphical interface to visualize, explore, and filter these anomalies. A functional, interactive dashboard is needed as the initial screen of the application to provide supply chain managers with a pleasant, dark-themed UI to monitor anomalies and easily access the FastAPI Swagger UI to register new movements.

## What Changes

- Create a functional Streamlit dashboard as the application's entry point (`src/dashboard/app.py`).
- Implement an interactive UI with a dark theme to analyze anomalies generated by the API.
- Provide KPI cards and charts (e.g., anomalies over time, anomalies by severity).
- Add filters (e.g., by date range, severity, warehouse) to explore the data.
- Include a direct link to the FastAPI Swagger UI for users to register new movements or interact with the API.

## Capabilities

### New Capabilities

- `anomaly-dashboard`: A Streamlit dashboard that serves as the entry point of the application, connecting to the API to retrieve and visualize supply chain anomalies with interactive filters, KPI cards, and a link to the API Swagger documentation.

### Modified Capabilities

## Impact

- **Code:** New Streamlit application in `src/dashboard/app.py`.
- **Dependencies:** Addition of Streamlit, Pandas, and Altair to the project dependencies.
- **Docker/Infrastructure:** The `dashboard` service in `compose.yaml` (which currently has a placeholder command) will be updated to run the new Streamlit app, and the `nginx.conf` will be updated to route root traffic (`/`) to the dashboard.
