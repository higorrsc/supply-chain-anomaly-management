# OpenSpec (`openspec/`)

This directory tracks the project's specifications and changes using OpenSpec, facilitating Spec-Driven Development (SDD).

## Structure

- **`specs/`**: Contains the main, authoritative specifications for the system's capabilities.
- **`changes/`**: Contains active and archived OpenSpec changes, which include proposals, design documents, and tasks.
- **`schemas/`**: Defines the OpenSpec workflow schemas used by the project.
